# Focus list

A Next.js App Router todo app with a REST API and a teal-accented UI.

## Features

- Add, rename, complete, and delete tasks
- Filter by All / Active / Done
- Clear completed tasks
- In-memory API at `/api/todos`
- Health check at `/health` → `{ "ok": true }`

## Getting started

```bash
bun install
bun run dev
```

Open [http://127.0.0.1:3000](http://127.0.0.1:3000).

```bash
bun run build && bun run start
```
